# 1-Bit ALU – Behavioral VHDL Design

## Overview

This project implements a 1-bit Arithmetic Logic Unit (ALU) using behavioral VHDL.

The ALU accepts two 1-bit data inputs, A and B, together with enable, inversion, function-selection, and carry signals. Based on the control inputs, the ALU can perform different logical and arithmetic operations, including AND, OR, inversion, addition, subtraction, and constant-output operations.

The design was implemented using VHDL `Process` statements rather than describing the circuit entirely at the gate level. A separate testbench was used to verify the different ALU configurations.

## ALU Structure

The basic structure of the ALU is shown below.

![ALU Block Diagram](Images/alu_black_box.png)

The ALU receives the following main inputs:

- **A, B** – 1-bit data inputs
- **ENA** – Enables or disables input A
- **ENB** – Enables or disables input B
- **INVA** – Controls whether A is inverted
- **F1, F0** – Function-selection inputs
- **Cin** – Carry input used by the arithmetic operation

The outputs are:

- **Output** – ALU result
- **Carry_Out** – Carry generated by the arithmetic operation

## Input Control

Before the selected ALU operation is performed, the input signals can be modified using the enable and inversion controls.

### Input A

`ENA` determines whether A is passed into the ALU.

When enabled, `INVA` can either leave A unchanged or invert it.

Conceptually:

```text
ENA = 0  → A input disabled
ENA = 1, INVA = 0 → A
ENA = 1, INVA = 1 → NOT A
