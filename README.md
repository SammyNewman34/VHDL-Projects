# VHDL Projects

A collection of digital design projects developed in **VHDL** using **Xilinx Vivado**.

The projects cover fundamental and intermediate VHDL and digital design concepts, including gate-level logic, combinational and sequential circuits, vector operations, and simulation and synthesis.

Each project is organized in its own folder and includes relevant VHDL source code, testbenches, and design/simulation results.

## Tools

* VHDL
* Xilinx Vivado
* RTL Design
* Digital Logic Design
* Simulation & Synthesis
